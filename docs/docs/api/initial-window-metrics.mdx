Insets and frame of the window on initial render. This can be used with the `initialMetrics` from `SafeAreaProvider`. See [optimization](/optimizations) for more information.

Object with:

```ts
{
  frame: { x: number, y: number, width: number, height: number },
  insets: { top: number, left: number, right: number, bottom: number },
  verticalCornerAdaptedInsets: { top: number, left: number, right: number, bottom: number },
  horizontalCornerAdaptedInsets: { top: number, left: number, right: number, bottom: number },
}
```

`verticalCornerAdaptedInsets` and `horizontalCornerAdaptedInsets` are the window's insets for the `cornerAdaptation` option of [`useSafeAreaInsets`](/api/use-safe-area-insets#corneradaptation).

**NOTE:** This value can be null or out of date as it is computed when the native module is created.
