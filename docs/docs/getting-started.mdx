## Supported react-native versions

| react-native-safe-area-context version | react-native version |
| -------------------------------------- | -------------------- |
| 6.x                                    | >= 0.82              |
| 5.x                                    | >= 0.75              |
| 4.x                                    | 0.64 - 0.74          |

## New architecture support

Version 6.x supports only React Native's New Architecture and requires React Native 0.82 or newer.
